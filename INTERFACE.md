# Карта интерфейса ElectroPlan — блоки и правки

> Интерфейс разбит на самостоятельные блоки (**B1…B12** + сквозной **B0**).
> Работаем по одному блоку: ты заполняешь под ним поля **ПРАВКИ — Внешний вид** и
> **ПРАВКИ — Функционал**, я реализую именно этот блок, не трогая соседние.
>
> Как заполнять: пиши свободным текстом под нужным полем. Можно списком, можно
> «было → стало». Ссылки на код (`файл:строка`) — мои якоря, их не трогай.

**Статус блока:** `[ ]` не начат · `[~]` правки собираются · `[»]` в реализации · `[x]` готово
**Приоритет:** P0…P3 (проставляй по важности)

Скелет разметки сейчас — [index.html](index.html), логика — [js/app.js](js/app.js),
стили — [css/styles.css](css/styles.css). Эти же блоки лягут в шаблон компонента Битрикс

- **Статус / Приор.:** [»] переработано под регионы/скелет, референс ОК, «чёрные» частично / P1
- **РЕШЕНИЕ (2026-07-21):** выбрано направление «тяжёлый CV: регионы/скелет». Реализовано в `app.js`:
  бинаризация → морфологическое замыкание (склейка штриховки/граней) → **выделение крупных связных компонентов** (`keepWallComponents`, убирает текст/мебель/таблицы/подписи — это мелкие кляксы) → осевые линии по толщине → сшивка обрывков. Тесты на реальных чертежах из `chertez/` через визуальный стенд (сервер сохраняет композит план+линии).
  - `scale_1200.jpg` (штриховка, референс заказчика) — **хорошо**: стены обведены цельно, без ложных линий по тексту.
  - `00b`, `639d…` (чёрные стены) — шум/таблицы убраны, но покрытие частичное (рабочий черновик).
  - Порог чувствительности и параметры (`closeR`, `tMin/tMax`, `minSpan`) подобраны эвристически — доводить под конкретные стили по мере надобности.
  - Остаётся: линии часто идут по внутренней грани, а не по оси; на тонких/сплошных стенах покрытие фрагментарнее. Ручное редактирование (этап 4) закрывает остаток.

**ПРАВКИ — Функционал:**
> Автообрисовка работала некорректно (см. скриншот заказчика). ВЫБРАН ОБЪЁМ: полная переработка (этапы 1–4). Сделано:
> 1. **Привязка координат** — линии мапятся под фактический `object-fit:contain` (единый масштаб + смещение); больше нет сдвига/растяжения.
> 2. **Детекция стен по толщине** — тонкие размерные/выносные линии отсекаются, двойной контур стены схлопывается в осевую линию; текст и сантехника не ловятся.
> 3. **Штриховка** — морфологическое замыкание (dilate→erode) заполняет промежутки штриховки перед детекцией.
> 4. **Ручная доводка** — клик по линии выбирает (свойства + подсветка) / удаляет (инструмент «Удалить»); ручная обрисовка с привязкой к сетке 25px и ортогональностью.
> Проверено на синтетическом плане (стены/текст/размерные линии). ⚠ Требуется прогон на реальном плане заказчика для тонкой настройки порогов (толщина стен, радиус замыкания штриховки).
