## Как пользоваться

1. В колонке «Префикс (серия?)» впишите название серии VIMAR напротив префикса.
2. Отметьте, какие префиксы/типы включаем в каталог (по ответам на [вопросы заказчику](вопросы-заказчику-каталог.md), раздел 1–2).
3. Отобранные коды добавляются в `tools/data/catalog-curation.json`, затем `npm run build:catalog`.
4. «Механизмы под вопросом» и «Прочее» — просмотреть выборочно: эвристика могла ошибиться в обе стороны.
