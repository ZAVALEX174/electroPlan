   накладка подходит ЛЮБОМУ варианту → не трогаем; ни одному → подмена под ПЕРВЫЙ (EPRoomVariants.placementIndex).
   Один вариант — ровно как сейчас.
3. «Готовые посты» (renderTemplates app.js ~442; сейчас только цвет выделенной комнаты, EPPosts.templateFitsRoomColor):
   видны посты, подходящие цвету ХОТЯ БЫ ОДНОГО варианта; вариант без цвета → всё.
4. Документы, смета, цена не трогаем.
