## Как пользоваться

- Статус вопроса: `[ ]` — ждёт ответа, `[x]` — отвечено (впишите ответ в строку **Ответ**).
- Отвечать можно прямо в этом файле, в строке `**Ответ:**`.
- **Как добавить вопрос:** скопируйте шаблон из раздела [«Шаблон»](#шаблон) в конце,
  поставьте следующий свободный номер внутри нужного раздела (напр. `1.4`, `2.5`).
  Новые темы — новым разделом (`### 8. …`).
- «Наше предложение» — вариант по умолчанию: если он устраивает, достаточно
  написать «да, по умолчанию».
