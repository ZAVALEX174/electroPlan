2. `npm test` → ожидается 2826 pass / 1 fail (см. ниже про файл заказчика) / 2 skipped.
3. Точечно: `node --test tests/buttonFrame.test.js tests/buttonFrameCapacity.test.js tests/buttonFrameImage.test.js tests/buttonFrameBuilderWiring.test.js` → 30/30.
4. Мутации (должны краснеть): buttonsOf→3 (4 красных); appliesTo без гейта ≥2 прорезей (1 красный);
