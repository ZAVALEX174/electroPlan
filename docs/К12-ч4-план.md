## Предложение решения (одно правило — один модуль, §7.1)
Новый модуль `js/buttonFrame.js` (EPButtonFrame): (а) `isButtonFrame(frame)`, (б) `buttonsOf(item)` = 2 у двойной клавиши 22751,
(в) `spanIn(item, frame)` = buttonsOf в кнопочной накладке, иначе mechanismSpan(item); (г) раскладка кнопок по окнам (ряд →
горизонтально, два ряда → вертикально) и доля лица на каждую кнопку. Подключать ЧЕРЕЗ ОДИН шов: deps.mechanismSpan
получает накладку (обёртка `spanForFrame(frame)` создаётся в одном месте и передаётся всем потребителям выше) — НЕ
править вызовы по одному (край «забыли одно место»).
