## Развилки для владельца (с рекомендацией)
1. Когда прятать шаг: (а) одно значение во всём каталоге; **(б) одно значение в текущем отборе** — одно правило и для
   автозаполнения, и для цвета механизмов. Прятать в окне, в списках и в подсказке конструктора; сохранённое значение не стирать.
2. Автозаполнение: **всё, кроме стандарта** (стандарт = коробки/суппорты = деньги); шаг с единственной плиткой заполнять и пропускать.
3. «Никель матовый» без серии не заполнит ничего — **честно заполнять только однозначное**, сказать заказчику (альтернатива — цвет раньше серии).
4. Цвет механизмов: **(а) шаг в подборе после цвета + поле комнаты**; галочка поста фильтрует по нему, если не задан — по цвету
   накладки как сейчас. Решить: фильтровать ли без галочки; новое имя галочки; при смене цвета накладки цвет механизмов не стирать
   (только при смене серии/стандарта).
5. Механизмы без цвета (702 из 1046): **оставлять видимыми** при выбранном цвете (иначе пропадут Linea/Tondo целиком).
6. П4 — уточнить у владельца/заказчика, о каком окне речь. До ответа не делать.
