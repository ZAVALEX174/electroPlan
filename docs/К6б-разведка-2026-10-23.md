## 2. Откуда брать «сколько добавлено»

- Правило: `EPPackRound.packRound(qty, pack)` js/packRound.js:19–26 (нет упаковки/ноль -> как есть; qty<=0 -> как есть; иначе `ceil(q/p)*p`). Добавлено = `packRound(Σ, pack) − Σ`.
- Σ по артикулу в проекте можно взять из двух сводов:
  1. `EPSupplierSpec.collect(supplierSpecData(light))` (supplierSpec.js:129, docs.js:213–293): строки `{code,name,unit,count,kind,assumed}` уже просуммированы по `codeKey`, но БЕЗ цен; сейчас собирается только в `exportSpecExcel` (docs.js:672) и для HTML-свода.
  2. Группы сметы: Σ по `est.groups[g].count × items[i].count` для items с `code` и `count>0` (kind: mechanism/sensor/lighting/backlight/support/box/frame/device). Тут же цена за штуку (`items[i].price`) и имя. НО в смете нет нормализации артикула (в build используется `String(it.code)` для подсветки/датчиков, 704, 724).
- Совпадают ли своды: по коду разбора — да, правила количеств общие и помечены «менять только вместе» с перекрёстным тестом: суппорт = `comp.supportCount` или число коробок (estimate.js:627 vs supplierSpec.js:201), коробка `comp.box||comp.boxFallback` (estimate 681 vs docs 270), датчики/подсветка из того же `comp.sensors/backlight`, цельные изделия подменены `effectiveMechanismIds` в обоих. Различия, не влияющие на добор: (а) реле схемы «Реле» есть только в своде и БЕЗ артикула (docs.js:290–291) -> упаковки/цены нет; (б) пробелы подбора без артикула — в своде строкой, в смете `code:null`; (в) «суппорт не требуется» в смете `count:0`. Явной сверки «Σ по артикулам сметы == supplier.collect.rows[].count на реальных проектах» в тестах я НЕ нашёл — её надо написать.
- Нормализация кода: `codeKey = c => String(c).replace(/\s+/g,"").toUpperCase()` — ДВЕ копии: supplierSpec.js:122 (не экспортируется, api = {buildHtml,collect,kindFromCatalog}) и specExcel.js:245. В estimate.js третьей нет. В живом каталоге (2868 позиций, проверено node): артикулов с пробелами/нижним регистром 0, коллизий codeKey 0, `packs` покрывает все 2868; упаковка >1 у 1676, =1 у 1192 (у них добор всегда 0); позиций без цены 0.
- Цена добора: каталожная цена за штуку = `items[i].price` (евро), далее ТОЛЬКО через `pricedUnit/shownSum` (цена штуки округляется в валюте показа ДО умножения: 7 × 25,79 € при курсе 92,5 = 16 699,06). Лист «По артикулам» уже считает `Сумма = shownSum([{unitPrice,count}])` (specExcel.js:321) — добор должен давать ту же сумму для того же количества.
