# К2 — отделка новых накладок по сайту VIMAR (сбор данных 18.10.2026)

Файл: `new-frames-finish.csv` (UTF-8 с BOM, «;»), 405 строк — все накладки с группой «Рамка»/«Рамка и Клавиша»
из `Номенклатура новая(1).xls`, которых нет в старом `Номенклатура новая.xls`.
Сейчас в новом файле у них «Цвет/Материал/Форма накладки» пустые (у всех 405).

## Где на сайте отделка
Страница продукта: `https://www.vimar.com/en/int/catalog/product/index/code/<артикул>` (it: `/it/it/...`).
Цвет — в названии и описании («2-module cover plate, painted technopolymer, silver»), в характеристиках
поле Colour показывает только грубый класс (Beige, Grey, Anthracite…). Материал — Material (Plastic/Metal) и
описание (technopolymer / painted technopolymer / metal). Surface finishing — Matt/Glossy. Формы нет; у ARKE она
в названии (Classic / Round). Ни у одной из 8 серий сайт не дал данных, которые противоречили бы суффиксу:
один суффикс — одна отделка во всех размерах.

## Расхождения «название ↔ сайт» и с старым файлом
1. Plana Up `.15`: в названии «голубовато-серая матовая», на сайте «matt dove grey» (горлица). В словаре есть «Горлица Матовая».
2. ARKE `B06` (19643/19644/19669.B06): на сайте металл. В старом файле 19641/42/52/53/54/57/68.B06 записаны как Технополимер.
3. ARKE `B26` в новом файле стоит у CLASSIC, сайт это подтверждает (19641.B26 — Classic). В старом файле B26 был только у ROUND (Скруглённая). Форма у ARKE определяется артикулом (1964x–1966x Classic), не суффиксом.
4. LINEA `30642.70`, `30654.70`, `30657.70`: таких кодов на сайте нет (404), есть `*.70.01` «brushed gold». В названиях: «матовое золото».
5. LINEA `.01` «конопляная»: на сайте it «canapa», цвет Beige. Это НЕ «Белая конопля» из старого файла (там Eikon Exe, стекло, «bianco canapa»).
6. LINEA `.20`/`.21`/`.22`: на сайте окрашенный технополимер (не металл), хотя .20 «серебро» и .22 «Metal» звучат как металл.
7. NEVE UP 09670.*: на сайте это «Blank cover» — сплошная заглушка на коробку 3М, а не рамка под механизмы. В новом файле у неё группа «Рамка».
8. Tondo: форму накладки сайт не даёт. Поставил «Классическая» по аналогии с Eikon (у Tondo круглые отверстия, сама накладка прямоугольная).
