# Фирменные каталоги VIMAR (PDF) — карта страниц

Заказчик положил в корень проекта два фирменных каталога. Сами файлы в git не идут
(`.gitignore`, ~155 МБ), но карта страниц нужна: по ней ищем ответы, не листая 258 страниц.

| Файл | Стр. | Что это |
|---|---|---|
| `c77a5022c6f0ab7850e1995d302713d9.pdf` | 258 | **WIRING DEVICES CATALOGUE (EN)** — полный каталог по всем сериям |
| `6e33a25290c7ddeab5ef45d5c989d746.pdf` | 88 | **PLANA (RU)** — одна серия, но по-русски и с русскими названиями групп |

Читать без внешних утилит: `pip install pymupdf`, дальше `fitz.open(...)` — `get_text()` для
текста, `get_pixmap()` для картинки страницы (pdftoppm/poppler в системе нет).

## Зачем это нам

1. **Внешний вид собранного изделия.** Каталожные сборки — эталон того, как должен выглядеть
   пост в конструкторе: накладка с ровными клавишами, зазор-шов между клавишами, у немецких
   накладок — отдельные окна под каждый пост.
2. **Цвет клавиши ≠ цвет накладки.** Устройства в каталоге идут колонками по исполнениям
   (Eikon: Grey / White / Next; Linea: Black / White / Canvas; Arké: Grey / White / Metal;
   Neve Up: White / Carbon Matt; Plana: Белый / Silver), а накладки — отдельным разделом со
   своей палитрой. Отсюда требование владельца «цвет клавиш может быть ЛЮБЫМ».
3. **Механизм + лицевая панель.** Разделы «interchangeable buttons» (1-module / 2-module)
   подтверждают модель «механизм отдельно, клавиша отдельно» — см. память проекта
   «Механизм выключателя по числу мест управления».
4. **Немецкий стандарт** — везде проходит как «71 mm between centres (German and French
   standard)», накладки 2+2 / 2+2+2 / 2+2+2+2, вертикальные и горизонтальные.
