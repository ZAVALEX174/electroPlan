# Б7 — Экспликация по комнатам: план (04.11)

Источник требования: §1.4 опросника — «да, если делаем комнаты». Записано в
docs/ОСТАТОК-РАБОТ.md пункт Б7. Разведка по коду — 04.11 (агентская, факты ниже с файл:строка).

## Фраза результата (рабочая; владелец может поправить)

«В меню "Документы" появится пункт "Экспликация по комнатам". Нажали — открылся документ
для печати/PDF: по каждой комнате заголовок с названием и площадью, под ним таблица её постов
(№, наполнение, накладка, модули, высота, назначение, цена) с итогом по комнате; в конце —
комнаты "Без помещения" и общий итог. Пустые комнаты (без постов) тоже показываем с площадью
и пометкой "постов нет".»

Решённые по умолчанию (владелец может изменить до реализации):
- формат: печатный HTML/PDF, как лист монтажника (window.open + автопечать);
- цены: показываем (цена поста + итог по комнате + общий итог);
- состав строки: №, наполнение словами, накладка, модульность, высота, назначение, цена;
- без отдельного окна настроек (шапка — общая docHeader); галочки состава — потом, если попросят.

## Факты разведки (04.11)

- Группировка по комнатам УЖЕ есть в листе монтажника: installSheetForProject (js/docs.js:612),
  заголовки <h2 class="room-heading"> (js/installSheet.js:498-513); «Без помещения» — в конец.
- Готовый сборщик строки поста: buildPostSheet (js/docs.js:439) — number, room, frameName,
  color, height, purpose, modules, fittings, priceText, картинки.
- Цена поста: postTotalCost (js/app.js:1944 → EPEstimate.postPriceShown) — в валюте показа.
- Площадь комнаты: roomDisplayArea (js/app.js:677) — ручная строка или авто м².
- Наполнение словами: EPPosts.fillSummary (js/posts.js:482).
- Кнопки документов: меню #docsDd (index.html:86), провязка EPDocs.attach (js/docs.js:766-768).
- Пайплайн всех документов: чистый модуль buildHtml(data, deps) → HTML-строка → window.open +
  document.write + автопечать. Прямого PDF нет.
- Кнопка Excel уже подписана «по артикулам и по помещениям» (index.html:88), но листов по
  помещениям в книге нет — по-комнатный Excel-лист можно добавить вторым шагом (specExcel.js).
- Тесты документов: чистый модуль через require (tests/installSheet.test.js и др.) + поведенческий
  стенд tests/helpers/appStand.js (docs.js уже в SOURCE_FILES стенда; новые функции объявлять
  `function name(` с начала строки, чтобы стенд их вырезал).

## План реализации

1. js/roomSheet.js — чистый EPRoomSheet.buildHtml(data, deps): шапка docHeader, по комнатам
   h2 «Название — площадь», таблица постов, итог по комнате, «Без помещения», общий итог,
   @page + автопечать. Стиль — как у installSheet.js.
2. js/docs.js — roomSheetForProject(): сбор данных (та же сортировка по комнатам, что
   installSheetForProject — компаратор вынести в чистую функцию, §7.1 «одно правило — одно место»),
   переиспользование buildPostSheet/postComposition/postTotalCost.
3. index.html — кнопка #roomSheetBtn «Экспликация по комнатам» в #docsDd; поднять ?v= у
   затронутых файлов (index.html, docs.js, roomSheet.js — новый).
4. tests/roomSheet.test.js — чистый модуль: состав комнат, итоги, «Без помещения», пустые
   комнаты, порядок комнат = порядку на плане; + wiring-тест кнопки через appStand.
5. Проверка кадром: проект с 2–3 комнатами и постами → кадр экспликации; npm test зелёный.
6. Коммит; запись в HANDOFF.md, отметка в docs/ОСТАТОК-РАБОТ.md (Б7 → [x]) и в
   docs/ЭТАПЫ-РАЗРАБОТКИ.xlsx (статус/дата/коммит — как требует шапка ОСТАТКА).

## Открытые вопросы (не блокируют; по ответу — второй шаг)

- Лист «По помещениям» в Excel-книге (подпись кнопки это уже обещает).
- Галочки состава экспликации (окно как у листа монтажника).
- Показывать ли цены — если заказчик скажет «экспликация без цен», выключим одной правкой.
