# З-К2-4 — коробка для панельных накладок Eikon Exe

## Проверено 21.11.2026

- В `../Номенклатура 2026-10-10.xls`, лист `VIMAR `, объединённое примечание `E2442:E2453` говорит «1 модуль центрально в коробку на 2 модуля». Оно охватывает `22671.1.01` и `22671.1.03` (а также соседние `22672.1.*`). Примечание `E2504:E2515` говорит «1 модуль центрально в коробку и суппорт на 2 модуля»; оно охватывает `22681.1.01` и `22681.1.03` (и `22682.1.*`). У четырёх проверяемых артикулов указан итальянский стандарт. Артикула коробки в этих примечаниях нет.
- Текущий каталог содержит для сплошной стены двухмодульную `V71001` (круглая, Ø60 мм; также `V71001.AU`). В `js/catalog-vimar-attrs.js` она отнесена к `IT_ROUND/DE/FR`. Для `IT` прямоугольная коробка начинается с `V71303` на 3 модуля. `V71701` и `V71791` относятся к полой стене. `14902` — накладной IP55-корпус без подтверждённого типа стены, поэтому не является заменой врезной коробки.
- `js/postfit.js:103–131` жёстко отбирает коробки по стандарту, затем по типу стены и ёмкости. На текущем каталоге `findBox` для всех четырёх артикулов при `IT/solid` возвращает `V71303`, 1,04 € вместо требуемой двухмодульной коробки.
- [Vimar 22671.1.01](https://www.vimar.com/en/int/catalog/product/index/code/22671.1.01) и [Vimar 22681.1.01](https://www.vimar.com/en/int/catalog/product/index/code/22681.1.01) называют эти накладки панельными. [Панельный суппорт 21626](https://www.vimar.com/en/int/catalog/product/index/code/21626) у Vimar помечен как не подходящий для круглой коробки Ø60 мм; в номенклатуре заказчика и текущем каталоге этого суппорта нет. [V71001](https://www.vimar.com/en/int/catalog/product/index/code/V71001) — круглая врезная коробка для сплошной стены. Из этих данных совместимость `V71001` именно с четырьмя панельными накладками при монтаже в сплошную стену не следует.
