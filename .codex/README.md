# Хуки Codex для проекта

Конфигурация находится в `config.toml`, обработчики — в `hooks/project_hooks.py`.
На Windows используется установленный `python` и `php` из `PATH`; на других
системах — `python3`. Скрипт не зависит от Bash на Windows.

| Событие Codex | Проверка |
| --- | --- |
| `PreToolUse` (`apply_patch`) | Запрещает правки `bitrix/`, `.env*`, `.settings*.php`, `dbconn.php`. |
| `PostToolUse` (`apply_patch`) | Проверяет `php -l` для изменённых PHP-файлов. |
| `Stop` | Проверяет `php -l` для всех изменённых и новых PHP-файлов из `git status`. |

Codex загружает проектные хуки только после доверия проекту. Для каждого нового
или изменённого хука также требуется проверка доверия в интерфейсе Codex (`/hooks`
в CLI). Это штатное ограничение Codex; конфигурация проекта его не обходит.

Проверка `apply_patch` не перехватывает все способы изменения файлов, например
команды оболочки и специализированные инструменты. Хук служит дополнительной
защитой, а не заменой прав доступа и проверки изменений. PHP-проверки молча
пропускаются, если `php` отсутствует в `PATH`.
